### **常见网络设备名示例**

| 设备名     | 含义                      | 常见场景       |
| ------- | ----------------------- | ---------- |
| `wlan0` | 无线局域网接口（Wireless LAN）   | WiFi 连接    |
| `eth0`  | 有线以太网接口（Ethernet）       | 网线连接       |
| `lo`    | 回环接口（Loopback）          | 本地通信       |
| `wlan1` | 第二个无线接口                 | 多个 WiFi 网卡 |
| `ap0`   | WiFi 热点接口（Access Point） | 作为热点使用     |



##  网络设备名完整对照表

|设备名|含义|类型|常见用途|
|---|---|---|---|
|`wlan0`|WiFi Station（客户端）|STA|连接到路由器，作为客户端使用|
|`ap0`|WiFi Access Point（热点）|AP|作为热点，其他设备连接到此设备|
|`mesh0`|WiFi Mesh 网状网络|Mesh|多设备组网|
|`eth0`|以太网接口|Ethernet|有线网络连接|
|`lo`|回环接口|Loopback|本地通信（127.0.0.1）|
